# خريطة المساجد — إعداد الخرائط

التطبيق يستخدم `react-native-maps` بدون أي إعدادات إضافية على **آيفون**
(بيستخدم خرائط آبل تلقائيًا، بدون مفتاح API ولا أي تكلفة).

**أندرويد مختلف:** ما في بديل عن خرائط جوجل على أندرويد (ما في نظام خرائط
أصلي بديل زي آبل)، ولازم مفتاح Google Maps API عشان تظهر الخريطة فعليًا —
بدونه الخريطة بتطلع فاضية/رمادية.

## خطوات الحصول على المفتاح (مرة وحدة فقط)

1. روح على [Google Cloud Console](https://console.cloud.google.com/) وأنشئ
   مشروع جديد (أو استخدم مشروع موجود).
2. فعّل **Maps SDK for Android** من "APIs & Services" → "Library".
3. لازم تربط حساب فوترة (Billing Account) بالمشروع — جوجل بتعطي رصيد مجاني
   شهري ($200) بيغطي استخدام تطبيق متوسط الحجم بسهولة، بس البطاقة لازم
   تكون مضافة حتى لو ما رح تنخصم فلوس فعليًا.
4. أنشئ مفتاح API من "Credentials"، وقيّده (Restrict) على:
   - Android apps فقط
   - اسم الحزمة (Package name): `app.athr.mobile`
   - بصمة SHA-1 لتوقيع الإصدار (تقدر تجيبها من `eas credentials`)

## إضافة المفتاح للمشروع

بمجرد ما يصير عندك المفتاح، ضيفه بـ `app.json` تحت `expo.android`:

```json
"android": {
  "config": {
    "googleMaps": {
      "apiKey": "AIzaSy...المفتاح_هون"
    }
  }
}
```

هاد المفتاح مش سري بنفس معنى مفاتيح السيرفر — القيود المذكورة فوق (اسم
الحزمة + SHA-1) هي الحماية الفعلية، فمافي مشكلة إنه يكون داخل الكود.

بدون هاد الإعداد، ميزة خريطة المساجد بتشتغل بشكل طبيعي 100% على آيفون،
وعلى أندرويد بس الخريطة نفسها بتبين فاضية لحد ما يُضاف المفتاح.
