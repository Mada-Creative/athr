# أصوات الإشعارات المخصصة

هالمجلد لازم يحتوي 3 ملفات صوتية (قبل ما تعمل بناء (build) جديد وإلا الكود بيرجع
للصوت الافتراضي صامتًا بدون أي خطأ ظاهر):

| اسم الملف            | يُستخدم لـ                                                         |
| --------------------- | -------------------------------------------------------------------- |
| `adhan.wav`           | إشعار دخول وقت الصلاة (الظهر، العصر، المغرب، العشاء)                |
| `adhan_fajr.wav`      | إشعار دخول وقت صلاة الفجر تحديدًا (مقطع فيه "الصلاة خير من النوم") |
| `prayer_reminder.wav` | التذكير قبل الصلاة (مقطع "لا إله إلا الله وحده لا شريك له...")      |

## قيود مهمة (نظام iOS)

- **الحد الأقصى 30 ثانية لكل ملف** — أطول من هيك وiOS بيرجع للصوت الافتراضي
  بصمت (بدون أي رسالة خطأ). فلازم يكون مقطع قصير، مش الأذان الكامل.
- الصيغة المفضّلة: `.wav` أو `.caf` أو `.aiff` (لأندرويد بينفع `.mp3`/`.wav`
  بردو، بس خلّينا موحّدين على `.wav` لكل الملفات الثلاثة).
- بعد ما تحط الملفات هون، لازم بناء (build) جديد كامل عشان تنضم لملف
  التطبيق — تعديل ملفات صوتية ما بينفّذ عبر تحديث JS بس.

## باقي الإشعارات

كل الإشعارات التانية (تذكير الأذكار، سنن الجمعة، الصيام، بطاقات أثر) ضلّت
عالصوت الافتراضي متل ما هي، ما تأثرت بهالتغيير.
